Content Flow Studio 개인정보 처리방침

시행일: 2026년 10월 14일 · 운영자: sonit.kr
이 문서는 Content Flow Studio와 DOT 초안 중계 기능의 개인정보 처리방침 초안입니다. 실제 공개 전 운영자 연락처와 서비스 운영 환경을 확인하고 필요한 법률 검토를 진행해 주세요.

1. 처리 목적

Content Flow Studio는 사용자가 입력한 콘텐츠를 검토하고, 선택한 워크스페이스·템플릿·채널에 맞춰 예약 발행할 수 있도록 다음 목적에서 정보를 처리합니다.

  • 콘텐츠 초안, 이미지, 템플릿 및 워크스페이스 저장·미리보기
  • 사용자가 승인한 SNS 예약 발행과 발행 상태 확인
  • Threads, X, Instagram, Facebook 등 사용자가 직접 연결한 계정의 인증·연결 상태 관리
  • DOT가 전달한 초안을 올바른 워크스페이스로 전달하고 중복 접수를 방지

2. 처리하는 정보

  • 사용자가 입력하는 원문, 플랫폼별 수정문, 이미지·워터마크·템플릿 설정
  • 워크스페이스, 예약 시각, 채널, 작업 상태 및 오류 기록
  • 연결한 SNS의 계정 식별자·표시 이름·토큰 등 인증에 필요한 정보
  • DOT 요청의 중복 방지를 위한 요청 식별자와 연결된 워크스페이스 식별자

서비스는 위 목적에 필요한 범위에서만 정보를 처리하며, 비밀번호를 평문으로 저장하지 않습니다. 연결 토큰은 운영 환경의 보호 기능을 사용해 보관합니다.

3. 제3자 제공 및 외부 전송

사용자가 발행 대상으로 선택하고 승인한 경우에만 해당 콘텐츠가 선택한 SNS 사업자의 API로 전송됩니다. DOT 중계 기능을 사용할 때 초안은 사용자가 설정한 중계 주소를 거쳐 Content Flow Studio로 전달됩니다. 승인하지 않은 초안은 SNS에 게시하지 않습니다.

4. 보관 및 삭제

콘텐츠·예약·워크스페이스 정보는 사용자가 삭제하거나 서비스 운영에 필요한 기간 동안 보관됩니다. 사용자는 앱의 워크스페이스·휴지통·연결 관리 기능을 통해 데이터를 삭제하거나 연결을 해제할 수 있습니다. 삭제된 휴지통 항목은 복구할 수 없도록 영구 삭제할 수 있습니다.

5. 안전성 확보 조치

  • 관리 API와 발행 기능은 인증된 로컬 또는 보호된 연결에서만 사용하도록 제한합니다.
  • 연결 토큰과 데이터베이스 백업은 타인에게 공유하지 말고 안전한 장소에 보관해야 합니다.
  • 발행 응답이 불확실한 경우 자동 재발행하지 않고 사용자가 상태를 확인하도록 합니다.

6. 이용자 문의

7. 변경 사항

서비스 기능이나 처리 내용이 바뀌면 이 페이지에 변경 내용을 반영하고 시행일을 갱신합니다.
